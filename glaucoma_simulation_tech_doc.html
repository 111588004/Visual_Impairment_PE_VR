Glaucoma Simulation System
青光眼模擬系統技術架構書

文件摘要： 本文檔詳細說明了青光眼模擬系統的視覺渲染邏輯、臨床病理模擬機制，以及基於眼動追蹤的幾何投影數學模型。

1. Visual Simulation Model (視覺模擬模型)

本系統的核心目標是提供符合臨床特徵的視覺體驗。透過 Shader 逐像素運算，我們模擬了視網膜神經節細胞 (RGC) 受損後的三大主要視覺徵狀。

1.2 Rendering Strategies (渲染呈現方案 & 病理模擬)

針對不同應用場景 (如臨床視野測試 vs. 患者日常體驗模擬)，系統提供了兩種可切換的渲染模式：

Option A: Total Blackout (全黑模式) Option B: Blur Sampling (相對缺損模式)
Shader Mode 1
  • 臨床定義：模擬 絕對視野缺損 (Absolute Scotoma)，即該區域完全喪失感光能力。
  • 視覺效果：周邊區域強制輸出純黑色 (RGB 0,0,0)。
  • 優勢：運算極快 (O(1))，適合標準自動化視野檢查 (SAP) 的模擬。
Shader Mode 4
  • 臨床定義：模擬 相對視野缺損 (Relative Scotoma)，與大腦的「填補效應 (Filling-in)」。視力模糊且光感下降，但非全黑。
  • 視覺效果：採用 黃金螺旋 (Golden Spiral) 演算法進行 30~80 次採樣，產生高品質散景 (Bokeh)。
  • 優勢：高度擬真，適合展示患者真實的主觀視覺感受。
Clinical Pathologies (Option B 專屬病理特效):

Shader 在此模式下會額外施加 RGC 受損特徵：

  1. Contrast Reduction (對比敏感度降低):
    blurCol = lerp(blurCol, grayscale, _Desaturation);
    現象：周邊視野飽和度下降，趨於灰階。
  2. Light Sensitivity Attenuation (光敏感度衰減):
    blurCol *= (1.0 - _PeripheralDarkness);
    現象：光閾值升高，視野邊緣變暗。

2. Geometric Projection System (幾何投影系統)

為了在 VR 頭盔中精確呈現如「20度管狀視野」的臨床定義，本系統建立了一套嚴謹的幾何投影模型，將 3D 眼動訊號映射至 2D 平面。

2.1 Binocular Projection Diagram (投影原理圖解)

下圖展示了凝視射線 (Gaze Ray) 如何穿透定義了視野範圍的濾鏡層 (Filter Layer) 並聚焦於 3D 場景。

Figure 1. 雙眼凝視訊號穿透 110度 FOV 濾鏡層之投影示意圖

圖解核心分析：

  1. Filter Layer as Retinal Map: 中間的 2D 平面 (Filter Layer) 實際上模擬了視網膜的敏感度分佈。
  2. Angular Fidelity (角保真度): 無論 VR 頭盔的物理螢幕距離眼睛多遠，系統透過 Rectilinear Projection (直線投影) 公式，確保濾鏡上的每個像素點都對應正確的視角 \(\theta\)。
  3. Binocular Fusion: 左眼與右眼擁有獨立的 Filter Layer (由 Shader 分別處理 _GazeCenterLeft/Right)，這允許模擬雙眼視野不對稱的真實情況。

2.2 Sensitivity Transition Logic (病變過渡區邏輯)

真實的青光眼視野缺損並非如「管狀視野」般邊緣銳利，而是存在一個病變過渡區 (Transition Zone)。本系統在 GlaucomaFieldGenerator.cs 中實作了兩種擬真度模式，其敏感度 \(S\) 隨半徑 \(r\) 的變化遵循特定的衰減函數。

Mode A: Standard (Demonstration) Mode B: High Fidelity (Realistic)
  • 特徵：銳利邊緣 (Sharp Edge)。
  • 邏輯：在 20°~20.1° (直徑) 極窄範圍內，敏感度瞬間從 1.0 降至 0.0。
  • 用途：適合教學示範，明確展示「20度管狀視野」的定義邊界。
  • 特徵：柔邊漸層 (Soft Gradient)。
  • 邏輯：將 20°~30° (直徑) 定義為過渡區，切分為 21 個敏感度階層 (Sensitivity Levels)，線性衰減 (1.0 \(\to\) 0.0)。
  • 用途：模擬真實患者視神經逐漸萎縮的模糊邊界，提供最接近臨床的主觀體驗。

2.3 Mathematical Model (數學模型)

A. 3D World to 2D Screen (注視點投影)

將眼動儀捕捉到的 3D 注視點 \(P_{world}\) 轉換為螢幕上的 UV 座標 \((u,v)\)：

$$ P_{clip} = M_{proj} \cdot M_{view} \cdot P_{world} $$ $$ [u, v]^T = 0.5 \cdot (P_{clip}.xy / P_{clip}.w) + 0.5 $$

B. Visual Field Mapping (視野角度映射)

計算濾鏡紋理上，距離中心半徑為 \(r_{uv}\) 的一點，其代表的真實視角 \(\theta\)：

$$ \theta = \arctan \left( r_{uv} \cdot \tan\left(\frac{FOV_{ref}}{2}\right) \right) $$

其中 \(FOV_{ref}\) 設為 110° (對應 VR 頭盔規格)。此公式保證了軟體生成的「20度缺損」在光學上是準確的。

C. Gradient Falloff Model (過渡區衰減模型)

針對 Realistic Mode 的過渡區，敏感度 \(S(\theta)\) 定義為線性插值函數 (Lerp)：

$$ S(\theta) = \begin{cases} 1.0 & \text{if } \theta < \theta_{start} \\ 1.0 - \frac{\theta - \theta_{start}}{\theta_{end} - \theta_{start}} & \text{if } \theta_{start} \le \theta \le \theta_{end} \\ 0.0 & \text{if } \theta> \theta_{end} \end{cases} $$

其中 \(\theta_{start}\) 為內徑邊界 (10°)，\(\theta_{end}\) 為外徑邊界 (15°)，對應 20°~30° 直徑範圍。

3. System Architecture (系統架構與實作)

本系統基於 Unity 元件架構設計，主要由以下三個模組構成：

  • Controller (GlaucomaRenderer.cs)
    系統中樞，負責串接硬體輸入 (Gaze Tracker) 與視覺輸出 (Material)。每幀更新 Shader 參數。
  • Field Generator (GlaucomaFieldGenerator.cs)
    數據工廠，負責利用上述數學公式生成 Sensitivity Map (RGB 紋理)。支援動態調整視野範圍 (如從 10度擴大至 30度)。
  • Shader Core (GlaucomaOverlay.shader)
    渲染核心，實作了所有的模糊算法、色彩處理與混合邏輯。
